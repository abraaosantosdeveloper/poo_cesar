## Briefing

Este repositório reúne os exercícios práticos da disciplina de Programação Orientada a Objetos (POO) em Java.
O objetivo é registrar a evolução das atividades propostas em aula, organizadas por listas e encontros.

## Como executar:

Para executar os programas, você precisa ter o Java SDK instalado na sua máquina. Se já os tiver, basta executar:

```bash
java ./<nome_do_diretorio>/<nome_do_projeto>/src/App.java
```
